# Chrome extension React + Ant Design 界面改造

## 目标与范围

优化现有扩展工具栏、网页操作弹窗、扩展面板和配置页的显示样式；为“加入临时任务”和“加入已有任务”提供可输入筛选的任务选择框。保留现有消息协议、任务创建和执行流程。

## 方案选择

- 原生 TypeScript + 自定义搜索选择框：依赖少，但需要自行维护组件交互。
- React + Ant Design：组件样式、键盘交互和状态反馈统一，需要引入 React 及组件依赖。用户已选择此方案。

## 界面与交互

使用统一的蓝色主色、浅色卡片、清晰的信息层级和一致的控件间距。扩展面板和配置页保留现有深色适配能力。长任务名完整可查，弹窗和列表限制高度并允许滚动，小屏幕不产生横向溢出。

任务选择采用 Ant Design Select，支持输入任务名称筛选、忽略大小写、清空后重新选择、键盘选择及无匹配提示。选项仍来自现有接口，仅展示后端返回的可用任务；任务加载中、加载失败和无可用任务分别反馈。输入搜索文本不视为已选任务，未选择有效任务时不能提交；提交期间避免重复操作。

## 实现约束

网页内操作界面继续使用 Shadow DOM 隔离宿主网站样式。Ant Design 样式和下拉浮层都放入隔离容器，验证下拉内容不会被弹窗滚动区域截断。关闭弹窗或销毁工具栏时清理 React 挂载与事件订阅。

仅在界面入口引入 React 和组件库，后台连接、爬虫执行与后端接口维持现有职责。所有资源打包到扩展内，不依赖运行时 CDN。构建方式、依赖版本和组件拆分由实现时结合现有配置确定。

## 验证

更新已有界面测试并覆盖任务筛选、无匹配结果、有效任务提交、关闭重开与键盘交互。运行扩展类型检查、测试、构建及 verify-agent-extension.mjs；检查构建产物，进行可行的界面预览，记录无法在真实 Chrome 扩展环境验收的部分。
